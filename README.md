# YaloséGames

Web provisional del estudio, centrada en Tourist Trap. HTML y CSS, sin JavaScript.

El blog (`/blog/`, oculto por ahora) lo construye GitHub Pages con Jekyll: cómo escribir posts en `BLOG.md`. Sistema de diseño en `DISEÑO.md`.

Para verla en local: `python -m http.server` y abre `http://localhost:8000`.

Si cambias `style.css`, ejecuta `python versionar.py` antes de subir (evita que el navegador use un CSS viejo).
